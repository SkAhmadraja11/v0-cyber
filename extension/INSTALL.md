# Phishing Detective - Enterprise Extension Installation

Thank you for downloading the Enterprise Security Agent.
To install this extension in Google Chrome, Edge, or Brave, follow these "Load Unpacked" steps.

This method is required for Developer/Private extensions that are not hosted on the public Web Store.

## Installation Steps

1. **Unzip** this file
   - Extract the `phishing-extension.zip` file to a folder on your computer (e.g., `Documents/phishing-extension`).

2. **Open Extensions Page**
   - In Chrome, go to `chrome://extensions`
   - (Or click the puzzle piece icon -> Manage Extensions).

3. **Enable Developer Mode**
   - Toggle the **"Developer mode"** switch in the top-right corner of the page.

4. **Load the Extension**
   - Click the **"Load unpacked"** button (top-left).
   - Select the folder where you extracted the files (select the folder containing `manifest.json`).

## Setup Complete!
- The specific "🛡️" icon will appear in your toolbar.
- The extension will now **automatically** scan every page you visit.
- If a threat is detected, you will see a red warning banner covering the page.
- You can click the icon anytime to see detailed risk analysis.

## Testing
- Visit a safe site (e.g., google.com) -> Icon should have "OK" badge.
- Visit a suspicious site -> Icon will turn RED and alert you.
